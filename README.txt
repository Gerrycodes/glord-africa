GLLØRD AFRICA — Starter prototype

Open index.html in a browser to preview the responsive frontend.

Included:
- Public landing page
- Demo user dashboard and task list
- Demo task submission flow
- Demo withdrawal request flow (minimum ₦2,000)
- Separate admin portal preview
- Task upload form and submission review
- Withdrawal review/status workflow
- Demo in-app activity notices

IMPORTANT:
This is a frontend prototype only. It does not include real authentication, a persistent database, live email notifications, verified referral/video/affiliate tracking, or bank-transfer processing. Do not use demo balances as real money. Before public launch, connect a secure backend, database, email provider and compliant payment workflow; implement server-side authorization and an auditable ledger.
